# ECHO

> **Every action leaves a trace. Every loop changes the outcome.**

**ECHO** is a futuristic time-loop puzzle game where the player must use recordings of their previous actions to overcome challenges, manipulate the environment, and escape an ever-repeating loop.

Built for **Prompt & Play**, ECHO combines atmospheric exploration, puzzle-solving, and a core time-echo mechanic to create a gameplay experience where your past becomes part of your present.

---

## 🎮 Game Overview

You are trapped inside a mysterious facility caught in a repeating temporal loop.

Each loop gives you another opportunity to observe, experiment, and adapt.

The unique twist?

**Your previous actions don't disappear. They become an Echo.**

Use your Echoes to:

* Activate switches simultaneously
* Distract hazards
* Trigger mechanisms
* Open previously inaccessible areas
* Coordinate actions across different moments
* Discover the truth behind the loop

Every attempt provides new information.

Every mistake becomes part of the solution.

---

## 🌀 Core Gameplay Mechanic

### The Echo System

At the end of each loop, the player's actions are recorded.

When the next loop begins, an **Echo** reproduces those actions exactly.

This allows the player to effectively cooperate with their past self.

```text
LOOP 01
Player → Presses Switch A
        ↓
        Echo Recording Created

LOOP 02
Echo → Presses Switch A
Player → Uses the opened path
        ↓
        New Area Unlocked

LOOP 03
Echo 1 → Switch A
Echo 2 → Switch B
Player → Solves Final Mechanism
```

The player must carefully plan actions across multiple loops to solve increasingly complex puzzles.

## 🎨 Design Philosophy

ECHO is built around one central idea:

> **Your past is a tool.**

Instead of simply restarting after failure, every loop provides another layer of information and possibility.

The game encourages players to:

**Observe → Experiment → Record → Adapt → Solve**

---

## 🧠 Example Puzzle

Imagine a room containing:

* A locked door
* Two pressure switches
* One movable object
* A security system

The player cannot activate both switches at the same time.

During **Loop 1**, the player activates Switch A.

During **Loop 2**, their Echo activates Switch A while the player moves to Switch B.

Both switches are now active.

The door opens.

The solution wasn't available in a single timeline.

**It required multiple versions of the player.**
